# 🏢 Gestión de Alquileres (PWA)

Una aplicación web progresiva (PWA) moderna y ligera diseñada para la administración integral de propiedades, inquilinos, contratos y control de pagos.

---

### ✨ Características Principales

* 🏢 **Gestión Multilocal & Empresas:** Soporte para inquilinos individuales y corporativos con asignación de múltiples habitaciones/locales en un solo contrato.
* 💰 **Control de Deudas y Abonos:** Registro de pagos completos y parciales (abonos) con actualización automática de saldos pendientes.
* 📲 **Integración con WhatsApp:** Envío de recordatorios y recibos de cobro consolidados en un solo clic.
* 📱 **PWA Instalable:** Funciona como app nativa en dispositivos móviles y escritorio con soporte offline.
* 🔐 **Seguridad Integrada:** Modales de confirmación con contraseña para acciones administrativas sensibles.

---

### 🛠️ Tech Stack

* **Frontend:** React + TypeScript + Vite + Tailwind CSS
* **Backend & Database:** Supabase
* **Deployment:** Vercel
